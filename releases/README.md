# SmoothPan releases

Pre-built plugin DLLs for **Windows** + **Dwarf Fortress Premium** (Steam, DF 50.x).

Each release folder contains `smoothpan.plug.dll`. You also need [DFHack](https://github.com/DFHack/dfhack/releases) installed for your exact game version — SmoothPan is a DFHack plugin, not a standalone mod.

| Release | Plugin build | Notes |
|---------|--------------|-------|
| [v1.1.0](v1.1.0/) | 3.11.52 | Middle-mouse smooth grab-pan; session cleanup fixes |
| [v1.0.0](v1.0.0/) | 3.11.46 | First public release — pan, mouse, mining designation |

If the plugin fails to load after a DF update, wait for a matching DFHack + SmoothPan build for that version.
